Insurance Claim Exploratory Data Analysis
Project Overview
This project performs an Exploratory Data Analysis (EDA) on an insurance dataset to understand the factors influencing medical insurance claim amounts.

The goal is to identify patterns and relationships between demographic, lifestyle, and health variables with claim costs.

Dataset Features
The dataset contains 1340 records with the following features:

Age

Gender

BMI

Blood Pressure

Diabetes

Smoking Status

Region

Insurance Claim Amount

Key Insights
The analysis reveals several important findings:

Smoking status has the strongest impact on claim amount

Higher BMI is associated with higher healthcare costs

Older individuals tend to generate larger claims

Chronic conditions like diabetes increase medical expenses
